One original fortune-cookie line for a software developer, at most 120 characters. A tired senior engineer judges the lines two at a time and picks the one that makes it smile and nod.

> Your future self will thank you for the comment you are too tired to write tonight.

## Run it

```sh
node main.ts
```

This writes the single fortune-cookie line to `/output/entry.txt` — deterministically, the same text on every run.
